# Архитектура PrivateTune

## Границы системы

Приложение — один статический Vue-экран без Router, backend и сетевых интеграций. Pinia хранит настройки интерфейса, статус входа, список устройств и последнее готовое показание. PCM-буферы никогда не попадают в Pinia, `localStorage`, Cache Storage или UI-компоненты.

```text
MediaStream (mono)
  → MediaStreamAudioSourceNode
  → AudioWorklet: кольцевое окно + overlap, без тяжёлого DSP
  → transferable Float32Array
  → Web Worker: DC removal → RMS/gate → pitchy MPM → clarity gate
  → Tuner Engine: harmonic candidates → matching/hysteresis → median → EMA
  → готовое показание (~25 запросов анализа/с, UI через Vue + rAF-интерполяцию)
```

Нулевой GainNode подключает worklet к destination, чтобы аудиограф обрабатывался, но пользователь не слышал feedback. Worker получает буфер transfer-операцией; после анализа ссылка освобождается и нигде не сохраняется. Если worker занят, следующее окно пропускается вместо накопления очереди и роста задержки.

## Модули

- `microphone-service.ts` инкапсулирует разрешение, классификацию ошибок, `enumerateDevices()` и остановку всех tracks. Его интерфейс `AudioInputSource` является seam для тестового источника.
- `audio-capture-worklet.ts` формирует перекрывающиеся PCM-окна через тестируемый
  `PcmFrameCollector`. Он не определяет pitch.
- `pitch-worker.ts` запускает только независимый DSP pipeline.
- `pitch-detector.ts` скрывает `pitchy`/MPM за локальным интерфейсом `PitchDetector`, поэтому алгоритм можно заменить без изменений Engine.
- `analysis-pipeline.ts` — детерминированный PCM seam, используемый worker и синтетическими тестами.
- `tuning-matcher.ts` сравнивает `f`, `f/2`, `f/3` с целями, поддерживает guided/automatic/chromatic и hysteresis.
- `pitch-smoother.ts` применяет медиану и EMA; при смене цели фильтр сбрасывается.
- `tuner-engine.ts` владеет AudioContext/узлами/worker и публикует только готовые результаты.

## Размер окна и задержка

Размер выбирается из минимальной MIDI-ноты текущего строя и фактического `AudioContext.sampleRate`: минимум 8192 samples, не менее семи периодов цели, округление вверх до степени двойки, максимум 32768. Hop рассчитывается примерно как `sampleRate / 25`, округлённый к Web Audio render quantum 128. При смене строя во время работы Engine повторно конфигурирует worklet и отбрасывает запоздавший результат предыдущей DSP-ревизии. Это даёт стабильное длинное окно для A0/B0 с частыми перекрывающимися обновлениями.

## Состояния и жизненный цикл

Микрофон не запрашивается при загрузке. Engine различает `idle`, `requesting`, `running`, `denied`, `missing`, `unsupported`, `no-signal`, `weak-signal`, `noisy-signal`, `error`. Операции запуска и остановки сериализованы, а номер поколения не позволяет запоздавшему `getUserMedia()` оживить уже остановленную сессию. Остановка освобождает worklet/worker/nodes, закрывает AudioContext и вызывает `stop()` у каждого MediaStreamTrack. Она вызывается кнопкой, при `pagehide` и при размонтировании. Смена входа во время работы перестраивает граф.

Wake Lock запрашивается только по пользовательской настройке и при активном тюнере, восстанавливается после возвращения вкладки и освобождается при остановке.

## Данные строёв

Встроенный каталог хранит только MIDI-номера, упорядоченные от самой толстой/низкой струны к самой тонкой/высокой. Отображаемые имена вычисляются с учётом диезов/бемолей и A4. Тесты проверяют уникальность ID, число струн, возрастание MIDI и контрольные пресеты.

Пользовательские строи валидируются как 4–9 MIDI-нот диапазона C0–E6. Две записи `localStorage` используют envelope `{ version, data }`; данные неизвестной версии, повреждённый JSON или невалидная структура не применяются. После чтения общий normalizer проверяет связь `instrumentKey → tuningId`, наличие пользовательского строя и допустимый индекс guided-струны. Поэтому частично очищенное хранилище не может оставить UI и Engine с целями от разных инструментов.

## PWA и сеть

Workbox precache включает только собранные HTML/CSS/JS, manifest, worklet и локальные иконки. Runtime API-кэшей нет. Единственная сеть после сборки — загрузка самих статических файлов с origin хостинга; приложение не выполняет fetch аудио, настроек или аналитики.
