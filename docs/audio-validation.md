# Валидация аудиодвижка

## Решение по detector

Начальная реализация использует McLeod Pitch Method из `pitchy 4.1.0` через собственный `PitchDetector`. MPM прошёл все заданные детерминированные критерии, включая низкий диапазон и доминирующую вторую гармонику в полном pipeline, поэтому дополнительный YIN-fallback не понадобился. Интерфейс detector оставлен изолированным для будущего A/B benchmark на записях реальных инструментов.

## Синтетический benchmark

Команда:

```bash
pnpm benchmark
```

Условия: sample rate 48 000 Hz, детерминированный hash-noise, окно из той же `chooseFrameSize()`, что использует Engine, DC removal, RMS gate, MPM и при harmonic-тесте guided matcher.

Результат контрольного прогона 10 августа 2026:

| Набор                      | Частоты                                                             |                    Критерий |  Результат |
| -------------------------- | ------------------------------------------------------------------- | --------------------------: | ---------: |
| Чистый sine                | 27.5, 30.8677, 41.2034, 65.4064, 82.4069, 110, 146.832, 220, 440 Hz |                    ≤ 1 cent | 9/9 прошли |
| Умеренный шум + гармоника  | 41.2034–440 Hz                                                      |                   ≤ 3 cents | 6/6 прошли |
| Низкий бас с шумом         | 27.5, 30.8677, 36.7081 Hz                                           |                   ≤ 5 cents | 3/3 прошли |
| Доминирующая 2-я гармоника | C2, fundamental 0.22 / H2 0.9                                       | ≤ 3 cents, без octave error |     прошёл |

Первоначальное минимальное окно 4096 дало 3.69 cents на одном шумовом E2-сигнале и не прошло лимит. Минимум был увеличен до 8192, после чего весь набор прошёл. Это зафиксированный benchmark-driven выбор, а не только теоретическая настройка.

Оценка времени накопления окна при 48 kHz:

- обычная гитара (E2 и выше): 8192 samples ≈ 171 ms, меньше лимита 500 ms;
- A0/B0 и соседний низкий бас: 16384 samples ≈ 341 ms, меньше лимита 800 ms.

После первого окна медиана пяти последних валидных измерений и EMA стабилизируют шкалу. Hop ≈ 40 ms поддерживает частые перекрывающиеся измерения; очередь не накапливается, если worker занят. Hysteresis удерживает предыдущую ноту/струну рядом с границей, а смена подтверждённой цели сбрасывает smoother. Тесты отдельно покрывают gate, median/EMA, hysteresis, guided target и `f/2` harmonic correction.

## Что benchmark не доказывает

Синтетика не моделирует корпусной резонанс, дребезг ладов, негармоничность очень толстых струн, clipping дешёвого интерфейса и DSP конкретного телефона. Физические проверки перечислены в `REAL_DEVICE_CHECKLIST.md` и не заявляются выполненными.
