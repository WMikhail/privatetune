# Проверка на реальных устройствах

Автоматические Chromium/WebKit-тесты и fake MediaStream не заменяют физическую проверку. Ни один пункт ниже не помечен выполненным без соответствующего устройства.

## iOS / iPadOS Safari

- [ ] Открыть HTTPS production URL на актуальном iPhone.
- [ ] Убедиться, что до нажатия «Включить микрофон» permission prompt отсутствует.
- [ ] Разрешить микрофон, настроить E2/A2/D3/G3/B3/E4 и проверить устойчивость portrait.
- [ ] Повернуть устройство в landscape; проверить safe areas, прокрутку и touch targets.
- [ ] Заблокировать доступ в Safari Settings, повторить запуск и проверить объяснение `denied`.
- [ ] Добавить PWA на Home Screen, один раз открыть онлайн, включить авиарежим и открыть повторно.
- [ ] Включить Wake Lock (если доступен в этой версии Safari), погасить/вернуть экран и проверить восстановление.

## Android / Chromium

- [ ] Повторить первый permission flow во встроенном Chrome.
- [ ] Проверить 360/390 px portrait и landscape, клавиатурную/BT-клавиатурную навигацию при наличии.
- [ ] Установить PWA, открыть офлайн после первого online-launch.
- [ ] Сменить системный вход, вернуть вкладку после background и убедиться, что зависших tracks нет.
- [ ] Проверить reduced-motion через системную настройку анимаций.

## Встроенный микрофон

- [ ] Гитара 6: E Standard и Drop C, по каждой струне от толстой к тонкой.
- [ ] Гитара 7: Drop A; проверить guided-режим на сильно заниженной 7-й струне.
- [ ] Гитара 8: F# Standard и Drop E; сравнить распознавание фундаментали и обертона.
- [ ] Бас 4/5: E1, B0, A0; записать дистанцию до микрофона и фактическую стабильность.
- [ ] Проверить тишину, вентилятор/речь рядом, слишком слабую атаку и clipping.

## Аудиоинтерфейс

- [ ] Подключить class-compliant USB-интерфейс до выдачи разрешения.
- [ ] После разрешения выбрать его в «Аудиовход», убедиться в безопасном перезапуске графа.
- [ ] Проверить инструментальный Hi-Z вход без hardware monitoring/feedback.
- [ ] Сравнить A0/B0 со встроенным микрофоном при одинаковом строе.
- [ ] Отключить интерфейс во время работы, проверить понятную ошибку и повторный запуск.
- [ ] Нажать «Остановить микрофон» и подтвердить, что индикатор захвата ОС погас.

## Что записать в отчёт

Для каждого устройства: модель, версия ОС/браузера, тип входа, sample rate (если видим), инструмент/струны, строй, наблюдаемая задержка, octave errors, поведение permission/offline/install и найденные ограничения. Не сохранять пользовательское аудио без отдельного осознанного согласия.
